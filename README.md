# Bucheen Landing Page

Modern ve responsive bir landing page projesidir.  
Figma tasarımına uygun şekilde React + Vite kullanılarak geliştirilmiştir.

##  Demo
https://bucheen-inky.vercel.app/

##  Kullanılan Teknolojiler
- React
- Vite
- Tailwind CSS

##  Özellikler
- Responsive tasarım (mobil & desktop uyumlu)
- Modern UI/UX
- Component bazlı yapı
- Temiz ve okunabilir kod

##  Notlar
Tasarım Figma referans alınarak geliştirilmiştir ve birebir uyum hedeflenmiştir.
